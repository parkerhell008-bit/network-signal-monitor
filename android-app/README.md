# مانیتور سیگنال شبکه (Network Signal Monitor)

اپلیکیشن اندرویدی (Kotlin) برای **پایش لحظه‌ای وضعیت سیم‌کارت و شبکهٔ موبایل**، نمایش اطلاعات کامل **دکل مخابراتی متصل**، **فاصلهٔ GPS تا دکل** با کمک سرویس OpenCelliD و اجرای **تست سرعت اینترنت** (پینگ / دانلود / آپلود) — همه در یک صفحهٔ تیره و راست‌به‌چپ (فارسی).

---

## ✨ امکانات

- **گیج ۲۷۰ درجه‌ای قدرت سیگنال** از `0` تا `-120 dBm` با عقربهٔ متحرک (انیمیشن `ValueAnimator`) و گرادیان رنگی قرمز → زرد → سبز، به‌همراه **۵ نوار سیگنال** رنگی.
- **جزئیات قدرت سیگنال**: `dBm`، `ASU`، سطح سیگنال (خیلی ضعیف تا عالی) و در شبکه‌های LTE/5G مقادیر `RSRP`، `RSRQ`، `SNR` و `RSSI`.
- **تشخیص نسل و نوع شبکه**: `5G – NR`، `4G – LTE`، `4G+ – LTE-A`، `3G+ – HSPA+`، `3G – UMTS/HSDPA/EVDO/CDMA/1xRTT`، `2G – EDGE/GPRS/iDEN`، `IWLAN` و… (نگاشت کامل همهٔ ثابت‌های `NETWORK_TYPE_*`).
- **وضعیت شبکه و سیم‌کارت**: نام اپراتور شبکه و اپراتور سیم‌کارت، `MCC/MNC`، کشور شبکه، وضعیت سیم‌کارت (آماده، قفل PIN/PUK و…)، **وضعیت رومینگ**، وضعیت داده (`CONNECTED/CONNECTING/DISCONNECTED/SUSPENDED`) و فعالیت داده (ارسال/دریافت/دو طرفه).
- **دکل متصل (سروینگ)**: `CID/NCI`، `TAC/LAC`، `PCI/PSC`، `EARFCN/ARFCN`، `MCC/MNC` و پهنای باند (LTE) — به‌علاوهٔ **لیست سلول‌های اطراف (همسایه)** با نشانِ رنگی نسل، RAT، شناسه‌ها و dBm هر سلول (هر ۳ ثانیه به‌روزرسانی می‌شود؛ در نبود داده از `GsmCellLocation` به‌عنوان جایگزین استفاده می‌شود).
- **پشتیبانی دو سیم‌کارت (Dual SIM)**: فهرست اشتراک‌های فعال از `SubscriptionManager` به‌همراه اپراتور و نوع شبکهٔ جداگانهٔ هر سیم‌کارت (با `createForSubscriptionId`).
- **فاصله تا دکل**: با یک دکمه، موقعیت فعلی با **GPS (FusedLocationProvider)** گرفته می‌شود، مختصات دکل متصل از **OpenCelliD** خوانده می‌شود و فاصله با **فرمول هاورساین** به‌همراه **جهت (بیرینگ) به فارسی** (شمال، شمال‌شرقی و…) نمایش داده می‌شود. فاصلهٔ به‌دست‌آمده کنار ردیف سلول سروینگ هم نمایش داده می‌شود.
- **تست سرعت اینترنت**: پینگ (میانگین ۱۰ نمونه + جیتر)، دانلود با **۴ جریان موازی** از سرور Cloudflare (تا ۲۵ مگابایت در هر جریان) و آپلود با **۴ درخواست POST موازی ۲ مگابایتی** — با نوار پیشرفت، نرخ لحظه‌ای و نتیجهٔ نهایی به **مگابیت بر ثانیه با ارقام فارسی**، و امکان **لغو تست** در میانهٔ کار.

## 📋 پیش‌نیازها

- **Android Studio** (نسخه Koala یا جدیدتر توصیه می‌شود) با **JDK 17**.
- Gradle 8.7+ و پلاگین Android Gradle **8.5.2** (اگر پوشهٔ `gradle/wrapper` در مخزن شما وجود ندارد، Android Studio هنگام اولین Sync خودش Gradle مناسب را فراهم/ساخت می‌کند).
- **حداقل اندروید ۸.۰ (API 26)** — هدف کامپایل: اندروید ۱۵ (API 35).
- برای دیدن اطلاعات تلفن/دکل حتماً روی **گوشی واقعی** اجرا کنید (امولاتور اطلاعات دکل واقعی ندارد).

## 🔐 مجوزها و دلیل درخواست هرکدام

| مجوز | چرا لازم است؟ |
|---|---|
| `READ_PHONE_STATE` | خواندن اطلاعات اپراتور، `networkOperator`، نوع شبکه (`dataNetworkType`)، `SignalStrength`، `getAllCellInfo` و فهرست اشتراک‌های فعال برای Dual SIM. |
| `ACCESS_FINE_LOCATION` و `ACCESS_COARSE_LOCATION` | از اندروید ۱۰ به بعد، خواندن `CellInfo` (شناسهٔ دکل‌ها) نیازمند مجوز موقعیت است؛ همچنین برای محاسبهٔ فاصله تا دکل با GPS لازم است. |
| `INTERNET` | تست سرعت (سرورهای Cloudflare) و پرس‌وجوی موقعیت دکل از OpenCelliD. |
| `ACCESS_NETWORK_STATE` | تشخیص اتصال اینترنت پیش از شروع تست سرعت. |
| `ACCESS_WIFI_STATE` | فقط برای پایش وضعیت Wi-Fi در برخی OEMها؛ منطق اصلی با `ACCESS_NETWORK_STATE` است. |

بدون تأیید مجوزها، کارت‌های مرتبط پیام راهنما نشان می‌دهند و مجوزها با `registerForActivityResult` در همان اجرای اول درخواست می‌شوند.

## 🔑 دریافت کلید رایگان OpenCelliD

برای محاسبهٔ **فاصلهٔ واقعی تا دکل** به یک کلید API رایگان نیاز است:

1. به سایت **https://opencellid.org** بروید و یک حساب کاربری رایگان بسازید.
2. بعد از ورود، از بخش **API Access / Token** کلید API (Token) خود را کپی کنید.
3. در برنامه، کلید را در کادر «کلید API سرویس OpenCelliD» وارد و دکمهٔ **ذخیره کلید** را بزنید (کلید در `SharedPreferences` ذخیره می‌شود).
4. حالا دکمهٔ **محاسبه فاصله با GPS** را بزنید؛ برنامه موقعیت شما را می‌گیرد و `https://opencellid.org/cell/get?token=...&mcc=..&mnc=..&lac=..&cellid=..` را فراخوانی می‌کند (برای LTE مقدار `TAC` به‌عنوان `lac` و مقدار `CID` به‌عنوان `cellid` ارسال می‌شود).

بدون کلید، تمام اطلاعات دکل به‌صورت محلی از خود گوشی نمایش داده می‌شود؛ فقط فاصلهٔ واقعی نیازمند کلید است.

## 🛠 ساخت پروژه در Android Studio (قدم‌به‌قدم)

1. **Android Studio** را باز کنید → `File > Open` → پوشهٔ `android-app` را انتخاب کنید.
2. صبر کنید تا **Gradle Sync** تمام شود (بار اول چند دقیقه طول می‌کشد و وابستگی‌ها از `google()` و `mavenCentral()` دانلود می‌شوند).
3. گوشی را با **USB Debugging** وصل کنید (یا یک دستگاه از Device Manager انتخاب کنید) و دکمهٔ **Run ▶** را بزنید.
4. برای ساخت APK:
   - مسیر `Build > Build App Bundle(s) / APK(s) > Build APK(s)` را دنبال کنید.
   - خروجی Debug در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.
5. برای نسخهٔ Release امضاشده: `Build > Generate Signed Bundle / APK > APK` و ساخت keystore خودتان.

اجرای خط فرمانی (در صورت وجود Gradle روی سیستم): `gradle assembleDebug`

## ⚠️ نکات مهم و محدودیت‌ها

- **سیگنال سلول‌های همسایه**: مقدار dBm سلول‌های همسایه از خود گوشی (`getAllCellInfo`) خوانده می‌شود، اما برخی سازندگان فقط سلول سروینگ را گزارش می‌کنند یا dBm همسایه‌ها را `MAX_VALUE` می‌دهند؛ در این صورت مقدار «—» نمایش داده می‌شود. شناسایی **نام دکل‌های واقعی و فاصلهٔ دقیق** نیازمند کلید OpenCelliD است.
- **API 31 به بالا** از `TelephonyCallback.SignalStrengthListener` استفاده می‌شود. طبق مستندات رسمی، `registerTelephonyCallback` از API 31 اضافه شده است؛ بنابراین بازهٔ **API 26 تا 30** با `PhoneStateListener` (deprecated ولی کارا) پوشش داده می‌شود و بازهٔ API 29/30 نیز همین مسیر را طی می‌کند تا از کرش جلوگیری شود.
- `dataNetworkType` فقط از API 30 خوانده می‌شود؛ در API‌های پایین‌تر از `networkType` (deprecated) استفاده می‌شود.
- فاصله تا دکل برای شبکه‌های **GSM/UMTS/LTE** پشتیبانی می‌شود؛ برای **5G NR** سرویس `cell/get` در OpenCelliD پاسخ استانداردی ندارد و پیام خطای مناسب نمایش داده می‌شود.
- **تست سرعت** به سرورهای Cloudflare وصل می‌شود؛ دانلود می‌تواند تا حدود **۱۰۰ مگابایت** (۴ جریان × ۲۵ مگابایت) مصرف داده، اما هر جریان پس از **۱۵ ثانیه** متوقف می‌شود تا مصرف داده کنترل شود. روی اینترنت سیم‌کارتی مراقب حجم بستهٔ خود باشید.
- برخی گوشی‌ها (مخصوصاً Xiaomi/Huawei) برای نمایش پایدار `CellInfo` نیاز دارند **سرویس موقعیت مکانی سیستم** روشن باشد.
- گوشی‌های بدون سیم‌کارت (تبلت‌ها) فقط بخش تست سرعت را کارا خواهند دید (`uses-feature` تلفن/GPS اختیاری تعریف شده است).
- این برنامه هیچ داده‌ای به سروری نمی‌فرستد؛ تنها درخواست‌ها به Cloudflare (تست سرعت) و OpenCelliD (فاصلهٔ دکل، فقط با کلید خودتان) ارسال می‌شود.
